# Make the Judge Laugh in One Line

One funny line, 200 characters or fewer. Our entry (92 characters):

> I put 'ask before spending money' in AGENTS.md. My agent asked the credit card. It said yes.

`main.py` writes that line deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), asserting the 1–200 character gate and verifying the written file matches.
